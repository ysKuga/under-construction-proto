# 目標設定になるマスの pointer を挙動に揃える

PR: #344（親: #137 backlog「目標設定になるマスの `cursor: pointer` を挙動に揃える」）

## 目的

- クリックで反応するマスへ `cursor: pointer` を付け、クリック時の挙動と揃える

## 背景・制約

- #343 で、直接移動できないマスのクリックは全て `onIndirectClick` へ委ねるようになった
  - 対象: 非隣接・隣接だが進入できないマス
- `GeoLayer` の pointer は `canEnterCell` で判定しており、挙動とずれている
  - 障害物・一方通行の壁で入れない隣接マス・EN 切れ時の隣接マスに pointer が付かない
- 現在マスはクリックしても何もしない（#341）

## 方針

- pointer は現在マス以外の全マスへ付ける
  - 現在マス以外は、クリックで何らかの反応がある
    - 進入可能: 移動
    - 障害物: 到達不能の通知
    - 一方通行の壁: 迂回経路の提示
    - EN 切れ: 吹き出しを揺らす
- `GeoLayer` の prop `canEnterCell` を `isCellSelectable` へリネームする
  - 進入可否と切り離し、選択可能表示の判定であることを名前で示す

## 懸念・リスク

- 障害物マスにも pointer が付き、進入できるように見える可能性がある
  - 障害物は絵文字で区別できるため、現状は許容する
