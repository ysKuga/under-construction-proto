# 決定事項（チェックポイントへのリセット）

- 2026-09-28: チェックポイント（開始位置）へのリセットの代価を決定（案A）
  - 戻すもの: actor の位置、EN（初期値まで）
  - 保持するもの: 盤面の状態（消費済アイテム・回復スポットの残回数・fog の到達済み）、携行アイテム
  - 代価: 進行の喪失と、消費済みの資源が復活しないこと。リセットを重ねるほど盤面は厳しくなる。到達済みの fog は偵察で得た知識として残す
  - 不採用
    - 案B（EN 上限の減少等の追加ペナルティ）: 案A で緩すぎると判明した時点で追加する
    - 案C（盤面ごと初期化）: 既存の `ResetProvider` による全体リセットと同じで、救済にならない
  - 携行アイテムの没収は代価にならない（リセットは手持ちがない場合に提示するため）
  - チェックポイントの位置は当面 `START_POSITION` 定数とする。複数チェックポイントが必要になった時点で store 化する
