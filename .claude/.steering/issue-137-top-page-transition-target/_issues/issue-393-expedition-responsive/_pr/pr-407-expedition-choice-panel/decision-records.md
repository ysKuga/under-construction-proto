# 決定事項（選択肢パネルの新設）

- 2026-10-25: steering を作成した
- 2026-10-25（レイアウト）: パネルは設定アイコンの右隣のボタンで呼び出す
  - 開いたパネルは呼び出しボタンを覆う（左端は設定アイコンの右隣）
  - 上端: 設定アイコンの上端。下の段へ重ね、状態表示より少し下へずらす
  - 選択肢の並べ方: 横並び（折り返し）
  - 開閉
    - 選択肢が現れたら自動で開き、無くなったら閉じる
    - 呼び出しボタンでいつでも開ける。選択肢が無い時は「選択肢なし」を表示
    - パネル右上のボタン: パネルを閉じる（目標設定は残す）
  - キャンセル: 選択肢の 1 つ
- 2026-10-25（Esc）: パネルは `popover="manual"` にし、開いている間 `useKeyLayer('Escape', 閉じる)` を積む
  - 経路の提示時: 1 回目の Esc でパネルを閉じ、2 回目で目標設定をキャンセルする（開いた順に積み、押すたび最上位を処理）
  - 理由: `popover="auto"` はブラウザが Esc で直接閉じ、`useKeyLayer` の層と同時に処理される
  - 設定ポップオーバーの同じ重複: 本 PR の前に別の fix PR で `manual` + `useKeyLayer` へ揃える
