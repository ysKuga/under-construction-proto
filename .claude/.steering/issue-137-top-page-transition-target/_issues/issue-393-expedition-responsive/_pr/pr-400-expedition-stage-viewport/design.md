# expedition の盤面を表示領域へ収める

PR: #400（親: #393）

## 目的

expedition の盤面を、テレビの画面のような表示領域へ収める。

- 表示領域の大きさは中身（盤面の広さ・傾き）で変えない
- スクロールを出さない（表示領域・ページとも）
- 映す範囲はカメラで決め、bot が十分に見える位置に合わせる

## 背景・制約

- 当初の方針（高さを傾けた床の実測に合わせる）は、確認で bot の頭・吹き出しが切れたため見直した
  - (decision-records.md 2026-10-19 見直し)
- 親 backlog の「表示範囲の追従（bot 中心等）」を本 PR へ取り込んだ
- 現状の 5×5 の盤面は表示領域に収まる
  - 確認は `GRID` を 10×10 へ一時的に変えて行った（コミットしない）

## 懸念・リスク

- カメラの rAF ループが停止中も毎フレーム実測する（吹き出しの追従と同じ方式）
- 移動中の滑らかさは実機で未確認（ヘッドレス Chromium のみ）
