# expedition の盤面を表示領域へ収める

PR: #400（親: #393）

## 目的

expedition の盤面について、以下をなくす。

- 画面からのはみ出し
- 傾けた床の上側にできる余白

## 背景・制約

- はみ出し・余白の扱いは親で決定済み
  - (../../decision-records.md 2026-10-19 表示領域)
- 吹き出し（`ActorOverlayLayer`）は切らない
  - 表示領域は `HexStage` の内側に置き、scene のみを包む
- 現状の 5×5 の盤面（約 320px）は、375px の画面に収まる
  - 幅の制限は、確認時に `GRID` を 10×10 へ一時的に変えて試す

## 懸念・リスク

- 傾きの transition（150ms）中に測ると、途中の高さになる
