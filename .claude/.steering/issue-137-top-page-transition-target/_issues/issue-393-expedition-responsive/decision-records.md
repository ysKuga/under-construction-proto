# 決定事項（expedition のレスポンシブ対応）

- 2026-10-19: #357 の backlog のレスポンシブ関連 3 項目を、#357 から独立させて #393 として切り出した
  - 理由: #357 の主題（本実装の移行）と関心が別で、複数 PR にわたるため
- 2026-10-19（実行順序）: 並べ方の切替 → 表示領域 → bot の状態表示（スマホの幅）の順とした
  - 理由
    - 表示領域の大きさ: 縦積み後のステージの領域が前提
    - bot の状態表示: 縦積み・表示領域を入れた後の残りの縦幅で決まる
      - 先に決めると作り直しになりやすい
  - 表示領域を追従・傾けた床・全体表示の切替へ分けた
    - 全体表示: アイテム等のゲーム要素が前提のため末尾
- 2026-10-19（並べ方）: `StageSection` を CSS grid にし、`md` 未満で並べ方を切り替える
  - `md` 未満
    - 1 段目: `Stage`（1 行を占める）
    - 2 段目: `BotStatusPanel`・`CellInfoPanel` を横並び（`grid-cols-[auto_1fr]`）
    - 3 段目: `MoveHistoryPanel`
  - `md` 以上: 従来どおり（`Stage`・`BotStatusPanel` を横並び → `CellInfoPanel` → `MoveHistoryPanel`）
  - `StageGroup` を廃止し、`stage`・`bot-status-panel` を `stage-section/_contents/` へ移す
    - 理由: `StageGroup` の横並びのままでは `md` 未満で崩せない
  - ページの外枠
    - `h-screen` を `min-h-screen` へ
    - `md` 未満は上寄せ
    - 理由: `h-screen` の中央寄せで、ステージの上下に隙間ができていた
- 2026-10-19（表示・非表示）: `BotStatusPanel`・`CellInfoPanel`・`MoveHistoryPanel` の表示・非表示の制御を検討する
  - grid の自動配置で、非表示にした要素を詰める
    - 例: `CellInfoPanel` のみ非表示 → `BotStatusPanel`・`MoveHistoryPanel` が横並び
  - `md` 以上で非表示にした時の並びは、着手時に決める
- 2026-10-19（表示領域）: 盤面のはみ出しの扱いを決めた
  - 盤面の画面からのはみ出し: 許容しない
  - 表示領域からのはみ出し（画面外）: 許容
  - 幅: 盤面の幅と画面幅（左右 16px を除く）の小さい方
    - はみ出し: `overflow-hidden` で切る
  - 高さ
    - 傾けた床の実際の高さに合わせる
    - 下端に揃える
    - 理由: `rotateX` は外枠の高さを傾ける前のまま残し、床の上側に余白ができる
    - 手段: 床の `getBoundingClientRect()` を傾きの書込み時に測る
    - 不採用: cos からの計算（perspective の補正が要るため）
  - 吹き出し（`ActorOverlayLayer`）: 切らない
    - 範囲外の bot の吹き出しが見える状態: 追従の導入まで許容

- 2026-10-23（タッチ端末でのマスの情報）: 最後にタップしたマスの情報を残す
  - 原因: タッチでは指を離した直後に `pointerleave` が必ず起き、`GeoLayer` の外枠が hover 解除を発行する
  - 手段: `GeoLayer` の `onPointerLeave` で、`pointerType === 'touch'` なら発行しない
    - `(hover: none)` でなく `pointerType` で判定する（マウス・タッチ両用の端末で操作ごとに切り替わる）
  - 隣接マスは情報を見る前に移動する: 許容
    - 障害物のマスは移動を拒否され目標扱いになるため、情報だけ見られる
  - 不採用
    - 2 段階タップ: 操作が増える、目標の再タップでのキャンセルと衝突する
    - 長押しで情報のみ: 気づきにくい、タイマー・click の抑止が要る
    - hover の detail へ `pointerType` を足し `useHoveredCell` で無視: 発行側で止めれば足りる
- 2026-10-23（選択肢パネル）: 選択肢の吹き出しをやめ、設定アイコンの右隣のパネルへ選択肢を並べる
  - 発端: 目標設定のキャンセルのヒントを設定アイコンの右隣へ置くと、床の左下のマスを覆った（PR #404 で検討、破棄）
  - 理由
    - 吹き出しは試作の意味合いもあった
    - SP 表示を標準とすると、bot の周囲に選択肢を展開する意味は薄い
  - 対象: 実行・中継点・キャンセル・EN スポットの使用・EN 切れの救助
    - 補給中・補給完了（お知らせ）: 吹き出しのまま
  - 並び
    - 上端・左端: 設定アイコンの右隣
    - 幅: 画面右端まで（`md` 以上はステージの右端まで）
    - 高さ: 状態表示と同じ。選択肢の多さ（ローグライク）を想定しスクロール
    - 下の段（状態表示・マスの情報）へ設定ポップオーバーと同様に重ね、状態表示より少しずらす
  - `md` 以上もパネルにする
  - 外した吹き出しの汎用部品（`bot-bubble`・`bubble-slots`）: `src/components/theater/` へ移し、任意で使えるようにする
  - PR の分け方
    1. 吹き出しの汎用部品を theater へ移す
    2. パネルを新設し、実行・中継点・キャンセルを移す
    3. EN スポットの使用・EN 切れの救助を移す
    4. マスの情報・手数の履歴の padding を `md` 未満で 4px にする（並行可）
  - 経路の提示時の吹き出しを 1 組にする検討: 不要になった
