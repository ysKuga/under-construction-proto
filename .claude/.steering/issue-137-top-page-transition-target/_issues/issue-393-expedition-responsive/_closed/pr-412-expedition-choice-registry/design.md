# 選択肢パネルへ選択肢を event で登録する仕組み

PR: #412（親: #393）

## 目的

選択肢の追加ごとに、パネル・組み合わせの props・hook の戻り値型が増えないようにする。\
各機能が選択肢を event で登録し、選択を event で受け取る形にする。

## 背景・制約

- PR #411 で、EN の選択肢の handler を部品 hook の引数・`UseChoicePanelContentReturn` へ足した
  - 選択肢 1 つの追加で組み合わせの型・ベース hook・部品 hook が変わり、密結合になる
  - 方針: 機能は event に一元化し、疎結合にする
- 選択肢の追加 PR で変えてよいのは、機能のディレクトリ・置く 1 行・event の型の追記のみにする
- #411 は本 PR の上で作り直す
- 同梱: パネルの自動表示・ピン留めの修正（#411 の作業中に見つけたパネル本体の不具合）
  - 選択肢が別の選択肢へ入れ替わった時に開かない（EN スポットの使用 → 救助等）
  - 上記の修正で、ピン留めの操作時の `beforetoggle` で state が閉じる
