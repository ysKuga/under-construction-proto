# タッチ端末でのマスの情報

PR: #404（親: #393）

## 目的

タッチ端末で、最後にタップしたマスの情報を `CellInfoPanel` へ残す。

## 背景・制約

- タッチでは指を離した直後に `pointerleave` が必ず起き、`GeoLayer` の外枠が hover 解除を発行する
  - 短いタップ: 表示が変わらないように見える
  - 長押し: 押している間だけ表示される
- 方針（../../decision-records.md 2026-10-23 タッチ端末でのマスの情報）
  - `GeoLayer` の `onPointerLeave` で、`pointerType === 'touch'` なら発行しない
  - 隣接マスは情報を見る前に移動する: 許容
