# 決定事項（設定ポップオーバーの Esc の `useKeyLayer` への統一）

- 2026-10-25: `popover="auto"` のまま、Esc の閉じを `useKeyLayer` の層へ載せる
  - 手段: 開いている間、Esc で閉じる層を積む。最上位で処理され、下の層へ回らない
  - 理由: `manual` にすると外側クリックで閉じる挙動が無くなる
  - ピン留め中: 層を積まない（従来どおり Esc で閉じない）
- 2026-10-25（確認）: expedition の全 story で、経路提示 → 設定 → Esc の順に 1 つずつ処理されることを確認した
  - 設定 → 経路提示の順は起きない（床のクリックが外側クリックになり、ポップオーバーが閉じる）
  - 外側クリックで閉じる挙動・ピン留め中に閉じない挙動は残っている
- 2026-10-26: `useKeyLayer` の `preventDefault()` を外した（revert）
  - 理由: ポップオーバーの層が常に最上位のため不要。ブラウザ標準の閉じは閉じ済みの要素へ走るだけ
  - 効くのは「開いたまま下の層が先に処理される」場合のみで、床のクリックで閉じるため起きない
  - 副作用（層が処理したキーのブラウザ既定動作を全て止める）を避ける
