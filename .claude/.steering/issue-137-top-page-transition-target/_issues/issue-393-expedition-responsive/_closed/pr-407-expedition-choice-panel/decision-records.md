# 決定事項（選択肢パネルの新設）

- 2026-10-25: steering を作成した
- 2026-10-25（レイアウト）: パネルは設定アイコンの右隣のボタンで呼び出す
  - 開いたパネルは呼び出しボタンを覆う（左端は設定アイコンの右隣）
  - 上端: 設定アイコンの上端。下の段へ重ね、状態表示より少し下へずらす
  - 選択肢の並べ方: 横並び（折り返し）
  - 開閉
    - 選択肢が現れたら自動で開き、無くなったら閉じる
    - 呼び出しボタンでいつでも開ける。選択肢が無い時は「選択肢なし」を表示
    - パネル右上のボタン: パネルを閉じる（目標設定は残す）
  - キャンセル: 選択肢の 1 つ
- 2026-10-25（Esc）: パネルは `popover="manual"` にし、開いている間 `useKeyLayer('Escape', 閉じる)` を積む
  - 後に `auto`（ピン留め中のみ `manual`）へ変更（2026-11-02 外側のクリック・ピン留め）
  - 経路の提示時: 1 回目の Esc でパネルを閉じ、2 回目で目標設定をキャンセルする（開いた順に積み、押すたび最上位を処理）
  - 理由: `popover="auto"` はブラウザが Esc で直接閉じ、`useKeyLayer` の層と同時に処理される
  - 設定ポップオーバーの同じ重複: 本 PR の前に別の fix PR で `manual` + `useKeyLayer` へ揃える
- 2026-10-26（表示条件）: 本 PR では選択肢ごとの表示条件・排他（`resolveVisibility`）を持たない
  - 実行・中継点・キャンセルは全て「経路提示中」で決まる。組み合わせ側で `waypoint-flow` を購読し、選択肢の配列を表示部品へ渡す
  - 排他が不要な理由: EN 切れ中は経路提示が起きない（中継点フローのクリア・`Expedition-propose-path` の拒否）
  - EN スポット・救助を移す PR で、選択肢ごとの表示条件の形（`visible$` 等）を決める
- 2026-11-02（置き場・寸法）: 組み合わせは `_contents/` でなく `stage/_components/choice-panel` に置く
  - 理由: `Stage` の床の左下（`belowFloor`）へ置く、`Stage` が中で使う部品。`stage-settings` と同じ形
  - 表示部品: `expedition/_components/choice-panel`
  - 高さ: 90px 固定（`md` 未満の状態表示と同じ）。あふれたら縦スクロール
  - 位置: CSS anchor positioning。上端・左端は呼び出しボタン、右端は画面右端から 16px（`md` 以上はステージの右端）
- 2026-11-02（表示部品）: パネルの幅を `w-auto` にした
  - 理由: ポップオーバーの UA スタイル `width: fit-content` で中身の幅に縮み、右端が画面右端 - 16px にならなかった
- 2026-11-02（Esc の層）: パネルの Esc の層は、ポップオーバーが開いた時（`toggle` event）に積む
  - 理由: 経路の提示でパネルが自動で開く時、経路をキャンセルする層（親の `Stage`）と同じ描画で有効になる。effect は子から親の順のため、開閉の state で積むとキャンセルの層が上になった
  - 中継点の選択中は、選択の層がパネルより後に積まれるため先に処理される（開いた順の通り）
- 2026-11-02（外側のクリック）: `popover="auto"` にし、外側のクリックで閉じる（設定ポップオーバーと同じ）
  - 手段: ブラウザが閉じた時（`toggle` event）に `close` を呼び、開閉の state を合わせる
  - 許容した点
    - 中継点の選択中の Esc 1 回で、選択の解除とパネルの閉じが同時に起きる（ブラウザ標準の Esc）
    - 盤面のマスのクリックでも閉じる。中継点の設置ごとに開き直しが要る
    - 設定を開くとパネルは閉じる（`auto` 同士）
  - 不採用: `manual` のまま外側の `pointerdown` で閉じる（Esc の順序は保てるが、閉じる処理の変更が増える）
- 2026-11-02（ピン留め）: 設定ポップオーバーと同じピン留めを付けた
  - ピン留め中は `popover="manual"`。外側のクリック・Esc・選択肢の消滅で閉じない
  - × で閉じるとピン留めも外れる。ピン留めの解除でも閉じる
