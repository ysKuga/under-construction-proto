# 決定事項（EN スポットの停止中使用と吹き出しの表示管理）

- 2026-09-29: #281 の残項目「スポットマスでの停止中使用（検討）」を #297 として切り出し、#281 を close した
  - 名称を「回復スポット」から「EN スポット」へ改める（日本語表記のみ）
  - 使用は移動の「実行」と同じ位置付けとし、1 回復あたり 300 ms で 1 ずつ回復する
- 2026-09-30: スポットでの回復の時間経過を決めた
  - 移動と同様に、時間経過を必要とする行為とする
  - 中断は想定しない。移動と同じく完了まで時間を経過させる
  - 回復量を先に指定し、その量に応じた時間（1 回復あたり 300 ms）を経過させる
  - 時間経過の管理は time-control の時間管理へ載せる想定とし、移動と回復を同列のログとして保持する（本 issue では導入しない）
- 2026-10-03: 吹き出しの表示管理の形を決めた（PR-2）
  - 吹き出しを一元的に格納する `BubbleSlots`（`_components/bubble-slots`）を設ける
    - 格納する吹き出しと表示状態は slots 用 store（`BubbleSlotsStoreProvider`）で保持する
    - 位置は上・中・下 × 左右の名前付きで定義し、表示中の吹き出しから順に割り当てる
    - 位置・表示状態は `BotBubble.Provider` 経由で吹き出しの props の既定値として渡す
  - 表示条件は吹き出しごとに Observable（`visible$`）で指定する
    - ゲーム側の store を `fromStore` で Observable へ変換して組み立てる
    - Provider が購読して store へ反映する。React の再レンダリングは表示状態を購読する slots のみ
  - 吹き出し間の排他は種類で指定する
    - 吹き出しへ種類 `kinds` と、表示中に隠す種類 `hides` を配列で指定する
    - EN 切れ（`hides: ['action']`）の表示中は、中継点・実行（`kinds: ['action']`）を隠す
    - 各吹き出しの表示条件へ「EN 切れでない」を書き込む形は採らない
  - 操作（クリック等）はゲーム側の hook に依存するため、slots でなく `_contents` 側の吹き出し（`*BubbleContent`）で結び付ける
  - 当初の案（表示順・スロット割当を `_contents` 側の hook で求める形）は変更箇所が大きく、上記へ作り直した
- 2026-10-03: EN スポットの使用の形を決めた（PR-3）
  - スポットは回復可能な残量で持つ
    - `ItemInstance` の `amount` を 1 回復あたりの回復量、`stock` を残りの回復回数とする（型は変えない）
    - 仮値は `amount: 1`、`stock: 4`
  - 回復量は自動で決める
    - 「上限までの不足分」と「スポットの残量」の小さい方（`countEnergySpotRecovery`）
    - 吹き出しは「回復？」1 つとし、量の選択は設けない
  - 時間経過は time-control 導入までの暫定として rxjs の `interval` で持つ
    - `FindPath-use-energy-spot` の listener が受理時に開始し、完了で終える
    - 開始・完了を区切る event は設けず、行為 store の切替で表す
  - player の行為を `_stores/player-activity`（`idle`/`moving`/`recovering`）で保持する
    - 移動・回復を同列の時間経過を伴う行為として扱う（time-control で同列のログとする想定に合わせる）
    - 移動中は `Stage07-move-start`/`Stage07-move-stop` の購読で切り替える
  - 回復中の他操作は移動中と同様に受け付けない
    - `Stage07` を非対話化する
    - 経路の提示・実行・アイテム使用・チェックポイントへのリセットを拒否する
    - 開始時に提示中の目標・中継点を消す
  - EN スポットの吹き出しの表示条件
    - スポット上で停止中、かつ回復できる（EN が上限未満・残量あり）
    - EN 切れ中も表示し、EN 切れの吹き出しと並べる（種類による排他の対象にしない）
    - 回復中は EN 切れの吹き出しを出さない（救済手段を提示しない）
- 2026-10-03: 回復中・完了時の吹き出しを決めた（PR-3）
  - 回復中は「補給中…」を表示する（`EnergySpotRecoveringBubble`）
  - 完了時は「補給完了！」を発言吹き出しで表示する（`EnergySpotRecoveredBubble`）
    - 一定時間（仮値 1500 ms）の経過、または次の行為（移動等）への切替まで表示する
    - 完了は行為 store の `recovering` → `idle` の切替を rxjs の `pairwise` で検知する（store にフラグを持たない）
    - 他の吹き出しの表示中は隠す。完了の吹き出しを種類 `notice` とし、他の全ての吹き出しへ `hides: ['notice']` を指定する
  - 両者とも表示専用のため、`BotBubble` の `onClick` を省略可能にした（省略時は本体を `disabled` にする）
