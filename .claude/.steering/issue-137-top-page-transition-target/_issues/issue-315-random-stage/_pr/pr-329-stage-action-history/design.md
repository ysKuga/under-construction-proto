# find-path のアクションの結果を履歴へ記録する

PR: #329（親: #315）

## 目的

手数の履歴に、移動・リセットに加えて、アクションに伴う結果の大半を記録して表示する。

## 背景・制約

- 履歴の記録・表示は #326・#327・#328 で対応済み（[../../_closed/pr-326-stage-move-history/design.md](../../_closed/pr-326-stage-move-history/design.md)）
  - 履歴 store（`_stores/move-history`）は `move`（1 手）と `reset` の 2 種類のみ
- 手数に数えるのは `move` のみ。追加する種類は手数に数えない

## 仕様

追加して記録するもの

- アイテムの携行（移動先のアイテムを拾った）
- 携行アイテムの使用（受理された時点）
- EN スポットでの補給（受理された時点）
- EN 切れ（player の `Energy-depleted`）
- ゴール到達（初回のみ）

記録しないもの

- 経路の提示・中継点の設置（操作途中で、結果を伴わないため）
- 拒否された操作
- EN の回復（アイテム使用・補給の結果として既に記録されるため）
