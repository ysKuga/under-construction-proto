# 生成盤面の通行不能箇所を経路に効く位置へ置く

PR: #320（親: #315）

## 目的

`generateStage` が置く通行不能箇所（障害物・一方通行）を、開始からゴールへの経路に影響する位置へ置く。
盤面の隅等、経路に関与しない位置へ置かれてパズルとして効かない盤面を減らす。

## 背景・制約

- 親 design: [../../design.md](../../design.md)「基本構成案」
- 前段
  - #318: `generateStage`。全要素を全セルからシャッフルで取り出し、到達性のみ検証
  - #319: 開始・ゴール間の距離に下限（`minGoalDistance`）
- 通行不能箇所の意味論
  - 障害物: セルへの進入不可
  - 一方通行: 退出方向の反対側の辺が壁。跨ぐ移動は方向を問わず拒否（`_lib/one-way.ts`）
- 到達性判定は既存 `findHexPath` + `canEnterForPath` を流用する

## 基本構成案

- 配置: 通行不能箇所の候補セルを、開始・ゴール間の経路帯に絞る
  - 経路帯: `hexDistance(start, c) + hexDistance(c, goal) <= hexDistance(start, goal) + slack`
  - 開始・ゴールを先に決め、残りセルから通行不能箇所 → その他要素の順に取り出す
- 検証: 通行不能箇所込みの最短手数が `hexDistance(start, goal)` より長い（迂回が発生する）配置のみ採用する
- `slack` は `GenerateStageParams` へ追加する

## 懸念・リスク

- 経路帯に置いても、一方通行の壁の向きが経路と平行なら効かない
  - 迂回発生の検証で盤面全体としては担保するが、個々の要素が効いている保証はない
- 条件を足すほど試行回数が増える。`maxAttempts` 内で生成できない seed が増えないか確認が要る
