# 決定事項（生成盤面の通行不能箇所を経路に効く位置へ置く）

- 2026-10-11: #315 の backlog「生成: 通行不能箇所（障害物・一方通行）が意味のない箇所に置かれやすい」に着手。PR #320 を先行作成した
- 2026-10-11: 経路帯へ絞る配置案は不採用。ランダム配置後に要素単位で判定・移し直す方式とした
  - 無意味: 1つ外しても最短手数が変わらない → 障害物は別セルへ、一方通行は同セルで向きを変える
  - 進入禁止: 開始から到達できないセルが生じる → 隣接セルへ移す
- 2026-10-11: 未定事項を確定。一方通行が全方向無意味なら別セルへ移す。1つずつ置いて都度判定し、原因特定を不要にする。2つ揃って効く組合せは許容
- 2026-10-11: 移し直しの上限は当初「数回」の想定から 100 へ引き上げた
  - 3 障害物 + 2 一方通行で seed 200 件を計測: 上限 5 → 5 件、30 → 157 件、100 → 198 件が生成成功
  - 原因: hex グリッドは最短経路が複数通りあり、1つで最短手数を延ばせる位置が少ない
  - 候補（空きセル × 向き）を全列挙し、効く位置から選ぶ方式なら試行の無駄を省ける（未採用）
