# 実装計画（中継点経由の経路統合と自動移動）

- [x] 中継点の経由順を最近傍法で決定する（lib 化 + テスト）
  - クリック順でなく、設置箇所が近い同士を接続する
  - 厳密な最適解（TSP）までは求めない
- [x] 中継点を経由した経路を `PathPreviewLayer` へ統合する
  - 区間ごとに `findHexPath` を呼んで経路を連結する
- [x] 経路に沿った自動移動を実装する
  - 入力は経路配列にする
  - 開始トリガー（実行ボタン / 確定操作）を決める
  - EN 不足時の扱いを決める
- [x] 「実行」ボタンを中継点吹き出しの反対側へ、同様の吹き出しとして実装し直す
  - 旧: `WaypointBubble` 本体の右隣へ absolute 配置した暫定ボタン
  - 対応: 共通の `BotBubble` を切り出し、`ExecuteBubble`（bot の左側）を新設
  - 文言: hover 中のみ「実行！」、それ以外は「実行？」
  - 形: bot を挟んで中継点吹き出しと反対側に配置
  - 見た目・挙動: 中継点吹き出しと同様（bot 方向コネクタ等）
  - 吹き出しの実装を共通化できそうであれば共通化する
    - 対象候補: コネクタ描画（`compute-connector-geometry`）・表示切替（`useCssToggle`）・ふわふわ揺れ等のスタイル
- [ ] EN 切れ時に経路選択ができてしまう問題を解消する
  - 現象
    - EN 切れ時でも非隣接クリックで経路を選択できる
    - その状態で「実行」を押すと、1 マスも移動せず停止し、経路プレビューが消えない
    - 移動途中で EN が切れた場合は経路が消える（最初の 1 マス移動時に `handleCellChange` がクリアするため）
  - 対応: EN 切れ時は経路を選択させないようにする
    - カーソルは現時点で既に EN 切れを反映して変わっている
- [ ] 経路プレビューを、移動したマスから順に消すことを検討する
  - 再レンダリングを避けることを重視する（[game-state ルール](../../../../rules/react/game-state.md)）
  - 下記「今後の検討候補」の「自動移動中に残り経路をプレビュー表示する」と合わせて検討する
- [ ] 「非隣接」クリックで指定するセルの呼び名を決める
  - 現状はコード上の区別（`onNonAdjacentClick`）がそのまま用語になっている
  - 候補: 「目的地」（「中継点」「経路」と並べて自然に読める）
- [ ] 非隣接クリックで選択した目的地にマーカーを表示する
  - 理由: 経路プレビューだけでは終端がどこか分からない
  - マーカーは既存の目標の旗（`GoalMarkerLayer`）・中継点の 📍 と見分けがつくものにする
- [ ] 中継点の選択中に吹き出しが経路を隠さないようにする
  - 以下のいずれかで対応する
    - 吹き出しを隠す
    - 吹き出しを透過する
    - 吹き出しを経路にかからない位置へ移動する
    - 吹き出しを「選択中」ステータス表示に切り替え、クリックで選択を解除できるようにする

  - 現状は「実行」時点でプレビューが消える（最初の 1 マス移動で `goalCell`/`waypoints` がクリアされるため）
