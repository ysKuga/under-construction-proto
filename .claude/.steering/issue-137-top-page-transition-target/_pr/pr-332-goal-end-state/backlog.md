# 実装計画（ゴール到達後の終了状態）

- [x] 到達判定のタイミング（セル進入時 / 中心到達時）を確認する
  - セル進入時のままで可。到達後は進入ガードで次のマスを拒否するため、bot はゴール中心まで歩いてから止まる
- [x] リセットで到達状態を戻す
  - `GoalStoreProvider` は `ResetProvider` 配下のため、既存の再マウントで戻る（追加実装なし）
- [x] 到達後に `Stage07` を非対話化する
- [x] 到達後に移動関連の表示を抑止する
  - 移動可能マス: 進入ガード（`perceived`）で全セル不可にし、表示対象なし
  - 経路プレビュー・目標マーカー・吹き出し: 既存の `handleCellChange`・`handleFollowPathEnd` の `clear()` で消える。非対話化で再設定不可
- [x] 到達時点で自動移動を打ち切る
  - 進入ガードで次のマスを拒否し停止。ゴール到達による停止は EN 不足の警告を出さない
