## 2026-10-09

- 表示手段: ステージ外の固定パネル。要素が多数に及ぶ場合はパネル内スクロール
  - マス近傍ツールチップは不採用（3D floor の画面座標変換・bubble との重なり）
- トリガー: ホバーで仮実装し、再レンダリングが多ければクリック対象の固定表示へ切替
  - 想定: hover 中マスを zustand vanilla store に保持、パネルのみ購読
  - `pointerenter`/`pointerleave` はセル境界通過時のみ発火。同一マスなら store 更新しない
  - `GeoLayer` へのコールバックは固定参照とし `memo` を崩さない
- 移動中の hover 表示は対象外（`pointerEvents` の 3D ヒットテスト問題が絡むため）
