# ゲームフェーズの導入

PR: #337（親: #137 backlog「ゲームフェーズを導入し、ゴール固有の分岐をまとめる」）

## 目的

- ゴール到達の判定を各所で直接読む形をやめ、フェーズと「フェーズごとに許可する操作」へ置き換える
- 今後フロー（詰み等）が増えても、各所へ分岐を足さずに表へ行を足すだけで済むようにする
- 挙動は変えない（リファクタ）

## 背景・制約

- #333〜#336 でゴール到達後の終了状態・演出を実装した結果、goal store の `reached`・`flagRaised` を直接読む箇所が約10箇所に散った
  - 操作の可否: 進入ガード・`Stage07` の `interactive`
  - 演出の可否: EN 切れ演出・吹き出し・EN 不足の警告
  - 表示: 操作パネル・セル情報パネル
  - ゴールの演出: 床上の旗・頭上の旗・両手上げ
- EN 切れ演出側がゴールを知る形になっている

## 方針

- goal store を game-phase store へ置き換える
  - `playing`: 通常
  - `clearing`: ゴール判定済み（セル進入時）、bot がゴール中心へ移動中
  - `cleared`: ゴール中心へ到着
- フェーズごとに許可する操作を表（`PHASE_PERMISSIONS`）で定義する
  - 操作の可否・演出の可否は表を引く。ゴールを直接参照しない
  - 表示（到達済み等）・ゴールの演出はフェーズを直接読む
- `player-activity`（`charging` 等）の統合は対象外
