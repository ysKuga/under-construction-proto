# パッケージ導入ルール

`npm i` で新規ライブラリを導入した場合、[docs/package/](../../docs/package/README.md) に記述を追加する。

## 手順

1. カテゴリディレクトリを決める(既存: `animation`/`3d`。該当なければ新設)
2. ライブラリ名がスコープ付き(`@react-three/fiber` 等)の場合、スコープ名でディレクトリを作成しその配下にパッケージ名ディレクトリを作成する
3. `README.md` を作成し以下を記述する
   - パッケージ名(見出し)
   - 公式ドキュメント URL
   - 概要(このプロジェクトでの用途)
   - peer dependency 制約等、バージョン選定に関わる注意点があれば追記する

## 例

`@react-three/fiber` を `animation` ではなく新設の `3d` カテゴリに配置。React 19 を要求する v9 系ではなく、本プロジェクトの React 18 と互換性のある v8 系を選定した経緯を「バージョン注意」として記述した。
