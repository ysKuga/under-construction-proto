# 同列ファイル間の import 回避

同一ディレクトリ内、関心ごとに分割したファイル同士で直接 import しない (`a.ts` が同列 `b.ts` を import する形)。循環 import の温床になる、依存方向が読み取りにくくなる。

## 対応

- **コード量が小さい場合**: 分割せず1ファイルに統合する。関心が強く結合している (片方の変化がもう片方の呼出を伴う等) なら、無理に分けない方が見通しがよい
- **分割を維持したい場合**: 共有される下位モジュールを別途切り出し、siblings はそこだけを参照する形にする (一方向)。sibling 同士が直接参照し合う形にはしない

## 例

`src/hooks/event/_registries/` (listener 登録数管理・pending Promise 管理・pending 変化通知) は当初3ファイルに分割、pending Promise 管理がpending 変化通知を import する同列参照が発生した。3つとも小規模かつ依存が1方向のみだったため `index.ts` 1ファイルへ統合、同列 import を解消した。
