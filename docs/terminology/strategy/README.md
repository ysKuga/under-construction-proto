# docs/terminology/strategy/

移動計画などゲーム内の意思決定に関わる用語について定義する。

## 戦略の階層

用語を検討する際の参考にする枠組み。\
上位ほど全体的・長期的、下位ほど局所的・即時的になる。

- 名称: 「戦略の階層」あるいは「戦略の 7 階層」（出典の資料は未確認）
- 階層（上位から順に）
  1. 世界観
  2. 政策
  3. 大戦略
  4. 軍事戦略
  5. 作戦
  6. 戦術
  7. 技術

## 目的と目標

- 目的 (purpose): 最終的に達成したい状態。全体的なニュアンスを持つ
- 目標 (objective): 目的を達成するために向かう、具体的な到達点

ゲーム内の文言では、局所的な到達点に「目的」を使わない。
