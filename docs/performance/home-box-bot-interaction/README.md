# トップページ box-bot の操作 state が UI を再レンダリングさせる

対象: [src/components/pages/home/index.tsx](../../../src/components/pages/home/index.tsx) (issue #131 / PR #132)

枠組み: [../README.md](../README.md) の「`useState` を使うかの判断」。

## 課題

### 操作のたびにページ component が再レンダリングされる

- ジャンプ・歩くの操作は本来 UI (見た目のレイアウト) に干渉すべきでないが、`useState` (`jumpCount` / `walking`) を使っており、操作のたびにページ component が再レンダリングされる。
- ジャンプ回数に応じて「歩く」ボタンの表示を切り替える仕様自体は意図通り。問題は、表示切替に関与しないタイミング (しきい値到達後のジャンプ、歩行 toggle) でも再レンダリングが走る点。

### 「3 回ジャンプしたら表示」と「3 回クリックしたら表示」は別挙動

- 現状は body/head クリック確定 (`onClick`) を数えているだけで、実際にジャンプ action が発火したかは見ていない。回転の押下継続中など、クリックしてもジャンプしないケースがカウントされる。
- 「ジャンプした回数」を数えるなら `ACTION_JUMP` の発火 (hopping の自動ジャンプを含む) を購読する必要があり、カウント対象の意味が変わる。
